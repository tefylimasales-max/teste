# Aprendizados da trilha GitHub Foundations

Durante a trilha GitHub Foundations, aprendi conceitos importantes para o desenvolvimento colaborativo de software.

## Principais conhecimentos

- Diferença entre Git e GitHub;
- Criação e gerenciamento de repositórios;
- Registro de alterações por meio de commits;
- Criação de branches para desenvolver funcionalidades isoladamente;
- Uso de pull requests para revisar alterações;
- Realização de merge entre branches;
- Documentação de projetos utilizando Markdown;
- Noções de GitHub Actions, Codespaces e segurança.

## Reflexão

A parte mais fácil foi compreender a criação de arquivos e commits. O trabalho com branches e pull requests exigiu mais atenção, pois foi necessário entender como as alterações são desenvolvidas separadamente e depois integradas ao branch principal.

Essa experiência mostrou como o GitHub ajuda a organizar projetos, registrar o histórico das modificações e facilitar a colaboração entre desenvolvedores.
